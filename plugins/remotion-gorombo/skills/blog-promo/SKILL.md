# Blog Post Promo

## Input
$ARGUMENTS

## Questionnaire
If not answered by the input, ask:
1. **What post?** — URL to the blog post
2. **Tone?** — Default: teaser/curiosity-driven. Other options: authoritative, casual, hype
3. **CTA?** — Default: "Read the full post" with the URL

## Script
Research the blog post. Extract: title, key takeaways (3-4 max), the hook (why should someone care), and any standout stats or quotes. Write a 4-scene script that teases the content without giving everything away — drive the viewer to read the full post. Present for approval before building.

## Scene Structure
- **Scene 1:** Hook — the question or problem the post answers. Make the viewer curious.
- **Scene 2:** Key points — 3-4 takeaways as animated text, just enough to show value
- **Scene 3:** Standout moment — the one stat, quote, or insight that makes someone stop scrolling
- **Scene 4:** CTA — "Read the full post" with URL on screen

## Visual Approach
- Treat it like a trailer — tease, don't teach
- Show just enough to create curiosity, not enough to satisfy it
- Key points as animated bullet list or cards
- B-roll background matching the post's subject matter

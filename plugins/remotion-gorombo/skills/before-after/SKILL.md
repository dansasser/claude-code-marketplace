# Before & After Comparison

## Input
$ARGUMENTS

## Questionnaire
If not answered by the input, ask:
1. **What's being compared?** — URL to research, or describe the old way vs new way
2. **How many comparisons?** — Default: 3-4 pain points vs solutions
3. **Tone?** — Default: dramatic contrast. Other options: humorous, factual, empathetic

## Script
Research the source. Identify 3-4 clear contrasts between the old way and the new way — cost, speed, reliability, effort, results. Each contrast needs a concrete detail (numbers, timeframes, real consequences). Present for approval before building.

## Scene Structure
- **Scene 1:** Hook — state the frustration with the old way
- **Scene 2-4:** Comparisons — one per scene, old way (red/negative) vs new way (green/positive). Show both sides with clear visual contrast.
- **Scene 5:** CTA — the clear winner, what to do next

## Visual Approach
- Strong color contrast: red/muted for "before", green/bright for "after"
- Each comparison can be split screen, sequential reveal, or strike-through the old way
- Numbers and stats animate in — cost comparisons, time saved, failure rates
- B-roll can match the context (frustration footage for before, clean/modern for after)

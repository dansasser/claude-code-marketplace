# Testimonial Video

Create a testimonial video by pulling real reviews from Google Maps, Facebook, Yelp, and other platforms. Animated star ratings and review cards.

**Usage:** `/testimonial <business name or URL>`

**Examples:**
- `/testimonial "Gorombo LLC"`
- `/testimonial https://gorombo.com`

Invokes the `remotion-gorombo:testimonial` skill with the provided arguments.

# Data Visualization Dashboard Video

Create an animated data dashboard video from a CSV file or data source. 4-panel layout with charts and KPIs.

**Usage:** `/data-visualization <CSV path or data description>`

**Examples:**
- `/data-visualization public/sales.csv`
- `/data-visualization quarterly revenue by product line`

Invokes the `openclaw-remotion-gorombo:data-visualization` skill with the provided arguments.

# Research Report

## Input
$ARGUMENTS

## Questionnaire
If not answered by the input, ask:
1. **What topic?** — What are we reporting on?
2. **Source?** — Specific URLs to pull from, or should I research broadly?
3. **Angle?** — What's the story? (e.g. growth, comparison, problem/solution, trend)

## Script
Research the topic and find real data points — stats, percentages, dollar figures, growth rates, comparisons. Then propose:
- A compelling title/headline
- 4-5 data points with sources
- The single most impressive stat (hero)
- Best chart types to tell the story (bar, donut, line, comparison)
- Panel layout

Present the data and proposed layout for approval before building. Cite sources.

## Panel Structure
- **Panel 1:** Hero stat — the one number that grabs attention
- **Panel 2-4:** Supporting data — charts, comparisons, breakdowns
- **Final panel:** Takeaway — one sentence conclusion with CTA if applicable

## Visual Approach
- Same as data-visualization — glass-morphism cards, SVG charts, count-up animations
- Data must be real and sourced — no made-up numbers
- Include source attribution as small text on each panel
